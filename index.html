Core Features

API Catalog

Maintain a structured catalog of your APIs with versions, tags, and mock responses — all stored locally.

  • • Add/edit API endpoints and example responses
  • • Tag and version APIs for quick filtering
  • • Persist data with localStorage for quick prototypes

Traffic Simulator

Generate mock traffic patterns and visualize request counts, latency, and error rates using simulated datasets.

  • • Simulate burst and steady traffic scenarios
  • • View request/response examples and timing
  • • Export simulated traces for manual analysis

Access Control

Set up mock users, roles, and API keys so you can prototype permission flows without a backend.

  • • Create users and assign roles
  • • Issue and revoke mock API keys
  • • Test role-based access in the browser
